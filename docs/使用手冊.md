# LINE 選股小幫手 使用手冊

每個交易日 17:00，系統依你設定的條件組合篩選台股（上市＋上櫃），結果存起來。你在 LINE 官方帳號裡隨時點開就能看，也能直接在 LINE 裡新增、修改、刪除條件。

> 部署與金鑰設定請看 [worker/README.md](../worker/README.md)。本手冊只講日常操作。

## 1. 一張圖看懂

```
17:00 GitHub Actions 篩選所有組合 ──▶ 結果存檔 ──▶ 有排推播的組合 → LINE 推播
                                          │
LINE 圖文選單 ─ 📊 查看結果 ──────────────┘（回覆訊息，免費不限次數）
              ─ ⚙️ 條件設定 → 設定頁（新增／修改／刪除組合）
              ─ 📋 用量與排程 → 推播額度、各組合推播日
```

## 2. 圖文選單

打開官方帳號聊天室，下方有三個按鈕：

| 按鈕 | 做什麼 | 用到推播額度嗎 |
|---|---|---|
| ⚙️ 條件設定 | 開啟設定頁，管理所有條件組合 | 不會 |
| 📊 查看結果 | 每個組合一張卡片，左右滑動 | 不會 |
| 📋 用量與排程 | 本月已用／剩餘推播則數、各組合推播日 | 不會 |

選單收起來時，也可以直接打字：`查看結果`、`設定`、`用量`。

## 3. 查看結果

1. 點 **📊 查看結果**，出現一排卡片，每張是一個條件組合。
2. 卡片上會寫資料日期、每個條件區塊各篩出幾檔。沒排推播的組合會標「🔕 不推播」。
3. 卡片下方三個按鈕：
   - **📊 看最新結果**：送出完整名單（股號、股名、關鍵數值）。
   - **⚙️ 改條件**：直接開這組的設定頁。
   - **▶️ 立即篩選**：用目前條件馬上重跑一次（見第 6 節）。
4. 看完一組，訊息下方有快速按鈕，可直接切換到其他組合，不用再滑卡片。
5. 最後一張卡片是 **＋ 新增條件組合**。

**資料日期旁出現紅字「條件已修改」**：代表你改過條件，但還沒重新篩選，目前看到的是修改前的結果。等下一個交易日 17:00，或按「立即篩選」。

## 4. 新增條件組合

1. 點 **⚙️ 條件設定** → 上方分頁最右邊 **＋ 新組合**（或結果卡片最後一張的「開啟設定」）。
2. 選一種策略範本，條件會依書中做法自動帶入：

| 策略 | 適合 | 主要條件 | 建議多久看一次 |
|---|---|---|---|
| 📈 長期成長股（CAN SLIM） | 持有半年～5 年 | 單季 EPS／營收年增、年度 EPS 年增、ROE、累季 EPS | 季報截止後（5/15、8/14、11/14、3/31） |
| ⚡ 中短線強勢股 | 持有 1 週～3 個月 | +DI／−DI／ADX、布林 %b 與帶寬、日週月 KD、5MA>20MA | 每 2～3 天或每週 |
| 🐳 主力操作股 | 持有數天～6 個月 | 千張大戶增加、法人連買、三個月累計同步、外資投信佔比、單日大買 | 每週一（集保週五晚公布） |
| 💰 高殖利率價值股 | 持有 1～3 年 | 現金股利、殖利率、本益比、淨值比、季線之上且上揚 | 每年 3 月起股利公告後 |
| 🧩 自訂組合 | 自由搭配 | 從空白開始，自己加區塊 | — |

3. 輸入組合名稱（會顯示在 LINE 卡片上）。
4. 按 **儲存**。新組合要等下一次篩選才有結果。

## 5. 修改條件

在設定頁上方點分頁切換組合，然後：

- **改數值**：直接改輸入框，或切換開關。
- **成長股強度**：成長股區塊上方 ①～④ 可一鍵套用。① 標準、② 較嚴格、③ 累季 EPS>0、④ 較寬鬆。
- **加區塊**：最下方 **＋ 加入其他條件區塊**，例如在成長股組合裡加「三個月法人同步」。
- **移除區塊**：區塊右上角 **✕**。
- **多個區塊怎麼合併**（有兩個以上區塊時才會出現）：
  - **分開列出**：每個區塊各列一份名單。
  - **只列同時符合**：取交集，只列所有區塊都通過的股票。
- **共同過濾與顯示**：這組所有結果都會套用，例如「站上月線」、最低均量、每區列出幾檔。
- 改完按 **儲存**。不想要剛才的修改就按 **還原**。

其他操作：

- **⧉ 複製這組**：以目前組合為底再做一組，適合做「同策略、不同門檻」的比較。
- **🗑 刪除這組**：刪除後無法復原。
- 最多 12 個組合（LINE 卡片的上限）。

## 6. 立即篩選

想馬上看到改完條件的結果時使用：

1. 卡片上按 **▶️ 立即篩選**，或設定頁下方 **立即篩選這組**（有未儲存的修改時，按鈕會變成「儲存並篩選這組」）。
2. 跳出確認，按 **確定**。
3. 約 1～2 分鐘後推播結果。

每按一次會用掉 1 則推播額度，所以每次都會先確認。

## 7. 推播設定與額度

LINE 免費方案每月 200 則推播。這套系統的原則是**看結果不花錢，只有推播花錢**：

- 設定頁上方「定期推播」勾選星期幾，那天 17:00 會推播這組結果；不勾就不推播，要看再自己點。
- 同一天有多組要推播時，會合併成 1 則，多勾組合不會多花額度。
- 目前預設只有 🐳 主力操作股 週一到週五推播，約 22 則／月。
- 剩不到 3 則時自動停止推播，結果仍然可以點來看。
- 沒有排推播的日子，連錯誤通知都不推。
- 點 **📋 用量與排程** 隨時查看本月用量。

## 8. 常見問題

**卡片寫「還沒有結果」？**
新組合要等下一個交易日 17:00 才會有結果，急的話按「立即篩選」。

**儲存時跳出「還沒加入條件區塊」？**
有一組組合是空白的，通常是點了「🧩 自訂組合」卻沒加區塊。畫面會自動切到那一組，從下方加一個區塊，或按「🗑 刪除這組」，再儲存。

**某個條件區塊沒出現在結果裡，或出現「略過」？**
可能是證交所、櫃買中心、公開資訊觀測站當天資料還沒出來或暫時連不上，隔天通常就正常；也可能是程式出錯，錯誤不會顯示在 LINE，只記在 GitHub Actions 的執行紀錄。其他區塊都不受影響。

**推播晚到？**
17:00 由 Cloudflare 準時觸發，篩選約需 2～3 分鐘。萬一證交所太慢導致失敗，17:30 會自動再試一次（17:00 那次失敗不會通知你，17:30 也失敗才會收到錯誤訊息）。萬一都沒觸發，GitHub 會在 18:00 之後補跑一次（GitHub 的排程可能再延遲幾個小時），不會重複推播。

**為什麼假日沒有推播？**
休市日沒有新資料，系統會自動跳過。

**成長股結果很少？**
CAN SLIM 條件本來就嚴格，可以改成「④ 較寬鬆」。季報截止日前，最新一季財報還沒出齊，結果也會偏少。

**設定頁打不開，或顯示權限錯誤？**
設定頁只限官方帳號的擁有者（你）使用，請從官方帳號聊天室的選單開啟，不要用分享出去的網址。

## 9. 名詞小抄

| 名詞 | 意思 |
|---|---|
| +DI／−DI／ADX | 趨勢指標：+DI 大於 −DI 代表多方較強，ADX 越高趨勢越明顯 |
| 布林 %b | 收盤價在布林通道的位置，≥1 代表突破上軌 |
| 帶寬 | 布林通道寬度，越小代表盤整越久、越可能突破 |
| KD 黃金交叉 | K 值由下往上穿過 D 值 |
| 千張大戶 | 持有 1000 張以上的股東，資料每週五由集保公布 |
| 三個月累計同步 | 外資與投信近 60 個交易日都累計買超 |
| ROE | 股東權益報酬率，本系統以近 4 季 EPS ÷ 每股淨值估算 |
